**#AWS Security and Identity Assignment.**

**1. To Create an IAM User with Restricted Permissions**

i. Sign in to the AWS Management Console

ii. Sign in as a user with administrative privileges.


**Step 2: Open the IAM Console**

i. In the search bar, type IAM and select it.
  You’ll be directed to the IAM Dashboard.
  

**Step 3: Create a New User**

i. Click Users > Add users.
ii. Username: Enter a name (e.g., restricted-user).

iii. Access type:
    Check Programmatic access if you want CLI access.
    Check AWS Management Console access if you want login to the console.

iv. For console access, create a password (can be autogenerated or custom).

v. Click Next.


**Step 4: Set Permissions**

You have options here, but to restrict:

i. Choose Attach policies directly.

ii. Search and select only the specific policy you want to assign.

    Example: Select AmazonS3ReadOnlyAccess if you want the user to only read from S3.

    Avoid giving full access like AdministratorAcces
    

**Step 5: Review and Create User**

i. Review all details.

ii. Click Create user.

ii. Download the .csv file or note the credentials (Access Key ID and Secret) for CLI use


**Step 6: Test the User’s Access**

For Console Access:
i. Go to the sign-in link provided (you’ll find it on the summary page).

ii. Log in with the new user credentials.

iii. Try accessing services:

**2. Set up Multi-Factor Authentication (MFA) for an IAM user.**

 To Set Up MFA for an IAM User
 i. Sign in to the AWS Console
 
 ii. Sign in as a user with admin permissions.
 

**Step 2: Go to IAM**

i. In the search bar, type IAM and click it.

ii. From the IAM Dashboard, click on Users.


**Step 3: Select the IAM User**

i. Click on the username you want to enable MFA for.


**Step 4: Enable MFA**

i. On the user summary page, click the Security credentials tab.

ii. Scroll down to the Multi-factor authentication (MFA) section.

iii. Click Assign MFA device.


**Step 5: Choose MFA Device Type**

i. Select “Authenticator app” (e.g., Google Authenticator, Authy, Microsoft Authenticator).

ii. Click Next.


**Step 6: Set Up the Authenticator App**

i. Open your chosen authenticator app on your phone.

ii. Scan the QR code shown on the AWS console.

    If you can’t scan, you can enter the manual secret key.

    The app will now generate 6-digit codes every 30 seconds.


**Step 7: Verify the MFA Device**

i. Enter two consecutive MFA codes from the app (back-to-back).

ii. Click Assign MFA.

  You should see a success message that MFA has been assigned.


**Step 8: Test the MFA Setup**

i. Sign out of the AWS Console.

ii. Go to the IAM sign-in URL.

iii. Enter the IAM user credentials.

iv. You’ll now be prompted for an MFA code from your app.

v. Enter the current 6-digit code to log in.



**3. Create and attach a custom policy to an IAM role.**

**To Create and Attach a Custom Policy to an IAM Role**

i. Go to your Management Console

ii. Log in with an admin-level account


**Step 2: Open the IAM Console**

i. In the AWS console search bar, type IAM and click it.

   You’ll land on the IAM Dashboard.


**Part 1: Create the Custom Policy**

**Step 3: Go to “Policies”**

i. On the left sidebar, click Policies.

ii. Click Create policy (top right corner).


**Step 4: Define Policy (Use JSON tab)**
i. Click the JSON tab.

ii. Paste your custom policy here.

    Example: Read-only access to a specific S3 bucket:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:GetObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::your-bucket-name",
        "arn:aws:s3:::your-bucket-name/*"
      ]
    }
  ]
}

iii. Click Next.

**Step 5: Name and Tag the Policy**

i. Give it a name, e.g., S3ReadOnlyCustomPolicy.

   (Optional) Add tags.

ii. Click Create policy.


**Part 2: Attach Policy to an IAM Role**

**Step 6: Go to Roles**

i. In the left sidebar, click Roles.

   Either:

ii. Click Create role, OR

  Choose an existing role to modify.


**Step 7: If Creating a New Role**

i. Choose Trusted entity (e.g., AWS service → EC2).

ii. Click Next.


**Step 8: Attach the Custom Policy**

i. In the Permissions step, search for the policy you just created (e.g., S3ReadOnlyCustomPolicy).

ii. Select it.

ii. Click Next, then Create role (or Update if editing).

Now the IAM role has your custom policy attached.
